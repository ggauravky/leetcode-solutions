## 💡 Common Patterns

Hard array problems typically involve:

1. **Advanced DP** - Multi-dimensional state management
2. **Segment Trees** - Range query optimization
3. **Binary Indexed Trees (Fenwick)** - Efficient updates and queries
4. **Monotonic Stacks/Queues** - Maintaining order properties
5. **Bitmasking** - State compression techniques
6. **Mathematical Insights** - Number theory, combinatorics
7. **Multi-pass Algorithms** - Strategic preprocessing
8. **Greedy + Proof** - Proving correctness of greedy choices
